# WHAT I LEARNT ABOUT CONDITIONS

* I learnt that a condition in Go can be either true or false. They can be used to perform different actions based on different conditions.
* Go usually supports the comparison operators from mathematics which are:
 1. Less than <
 2. Less than or equal <=
 3. Greater than >
 4. Greater than or equal >=
 5. Equal to ==
 6. Not equal to !=

* Additionally, Go supports the usual logical operators:

 1. Logical AND &&
 2. Logical OR ||
 3. Logical NOT !

* You can use these operators or their combinations to create conditions for different decisions.

* And i realise that in Go there different conditonal statementt these are:
 1. The if statement: which is used to specify a block of Go code to be executed if a condition is true.
 2. The if else statement: which is used to specify a block of code to be executed if the condition is false.
 3. The else if statement: which is used to specify a new condition if the first condition is false.
 4. the nested if statement: it is called the nested if because you can have an if statements inside an if statements.
